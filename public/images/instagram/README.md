# Instagram Feed Images

This folder contains images for the Instagram feed section on the homepage.

## Required Images

Please add 6 Instagram post images with the following names:

- `post-1.jpg`
- `post-2.jpg`
- `post-3.jpg`
- `post-4.jpg`
- `post-5.jpg`
- `post-6.jpg`

## Image Specifications

- **Format**: JPG or WebP
- **Dimensions**: 1080x1080px (square format, 1:1 ratio)
- **Optimization**: Compress images for web (max 200-300KB per image)
- **Content**: Showcase transformations, treatments, happy clients, before/after results

## Usage

These images are displayed in a responsive grid on the homepage Instagram section.
Users can click on any image to be redirected to your Instagram profile.

## Alternative: Connect to Instagram API

For automatic feed updates, consider implementing Instagram Basic Display API or using a third-party service.
